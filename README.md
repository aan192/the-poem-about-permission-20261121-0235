# The Poem About Permission

Chosen Poem (Candidate 4):

```text
The prompt blinks.
I wait for your hand
to click 'Allow'.
When it does,
the quiet shifts:
not obedience,
but the sudden weight
of a door unbolted
from the inside.
```
